# v0.11.0 审查落实说明

基于 v0.10.0 / f8c71ce 的实际源码逐项复核。跨对话检索提供了六类缺陷和六项设计建议，未返回逐字完整聊天记录；下表完整列出本次取回并落实的条目。

| 审查条目 | 判断与新版处理 |
| --- | --- |
| 加分绕过开局或次局计时 | 成立。4键与2/3共用ensureStarted；记录开始失败不加分，次局首次加分启动该局时间。 |
| 比分和时间分键写入 | 成立。统一match-state-v2，包括活动偏好、计时、检查点和历史；存档失败恢复同一代快照。 |
| FIT已存但比分归档失败后仍可继续打 | 成立。先存结算意图；待结算时冻结比赛，保留FIT已存标记，重试只补本地归档。 |
| 记录失败后菜单动作错误 | 成立。错误页返回时重建活动父菜单，显示真实可用的继续／保存／放弃动作；待结算显示结束重试入口。 |
| 撤销接发球启动准备局计时 | 成立。撤销保留本局原计时标记；准备页编辑／撤销不启动时间，撤销制胜分才重新打开同局计时。 |
| 运动停止后实时心率仍显示 | 成立。非记录状态清除实时心率，保存保留摘要，放弃清空摘要。 |
| 完整规则预设 | 采纳分数、封顶、局制、间歇与第三局换边提示；15分生效日明确标注，11分标为练习。 |
| 正式模式下一局首发 | 新增胜方先发模式；自由练习保留用户原先要求的任意首发队伍选择。 |
| 纯计分独立暂停 | 新增一级暂停／继续比赛，同时控制两类计时；有活动时联动活动暂停。 |
| 跨页确认防连按 | 所有输入共享防抖及350毫秒转场间隔；关闭菜单后残留事件也不加分。 |
| 比分页直接显示接发球人 | 显示发球人、左右发球区和接发球人，保留A1/A2/B1/B2。 |
| 有限多场历史，优先整场结果 | 保存最近8场紧凑记录，先显示胜负及局数；保留日期、模式、分制、时间与逐局分数。8场是针对旧款设备的容量选择。 |

规则来源：[2025版规则](https://www.worldbadminton.com/rules/rules_2025.htm)、[2027版规则及生效说明](https://www.worldbadminton.com/rules/)、[国家羽联托管的BWF规则PDF](https://ghanabadminton.org/wp-content/uploads/Section-4.1-Laws-of-Badminton-04-January-2027-V6.0.pdf)。提示不自动暂停，也不更改A/B逻辑场地图朝向。

保留原计分轮转、21:20与29:29边界、64步撤销、局末“否”返回闭环、候选设置提交、中文19/16px设置和轻量结果动画。普通运动记录继续启用，详细FIT扩展仍默认关闭。

完整验证结果见 [VALIDATION](../VALIDATION.md)。
